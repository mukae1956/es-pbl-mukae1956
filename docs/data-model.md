# 데이터 모델 초안

## 1. 문서 단위
- 검색 결과 한 건은 무엇인가: OTT 플랫폼에 등록된 콘텐츠(영화, 드라마, 예능 등) 한 편
- 이 문서 한 건이 사용자에게 보여 주는 정보는 무엇인가: 콘텐츠 제목, 장르, 줄거리, 출연진, 공개 연도, 평점, 시청 등급, 썸네일 이미지 경로

## 2. 대표 문서 예시
```json
{
  "content_id": "OTT-000123",
  "title": "심야식당",
  "genre": ["드라마", "휴먼"],
  "description": "밤늦게 문을 여는 작은 식당에서 벌어지는 사람들의 이야기를 그린 옴니버스 드라마.",
  "cast": ["배우A", "배우B"],
  "release_year": 2023,
  "rating": 4.6,
  "age_rating": "15세 이상",
  "runtime_minutes": 45,
  "episode_count": 12,
  "country": "KR",
  "language": "ko",
  "release_date": "2023-05-10",
  "popularity_score": 87.5,
  "view_count": 154320,
  "thumbnail_url": "/images/content/000123.jpg"
}
```

## 3. 핵심 field와 역할
Day 1에는 field의 검색 역할과 ES type 후보를 초안으로 적습니다. Day 2에 mapping과 함께 확정합니다.
| field | 예시 값 | 검색에서 맡는 역할 | ES type 후보 | 선택 이유 |
|---|---|---|---|---|
| title | "심야식당" | 전문 검색 | text (+ keyword 서브필드) | 사용자가 제목 일부만 입력해도 찾아야 하고, 정렬/집계용 정확 매칭도 필요 |
| description | "밤늦게 문을 여는..." | 전문 검색 | text | 줄거리 키워드로도 검색되게 형태소 분석 필요 |
| genre | ["드라마", "휴먼"] | 정확 조건 / 집계 | keyword | 장르별 필터링, 대시보드 집계(Top 장르)에 사용 |
| release_year | 2023 | 범위 / 정렬 | integer | 연도 범위 필터(예: 2020년 이후)와 최신순 정렬에 사용 |
| rating | 4.6 | 범위 / 정렬 | float | 평점 이상/이하 필터, 평점순 정렬 |
| view_count | 154320 | 정렬 / 집계 | long | 인기순 정렬, 조회수 합계·평균 집계 |

## 4. 검색 질문과 field 연결
| 검색 질문 | 사용할 field | 확인할 역할 |
|---|---|---|
| "심야식당" 같은 키워드로 제목/줄거리에 콘텐츠를 찾을 수 있는가? | title, description | 전문 검색 |
| 특정 장르(드라마)만 필터링해서 볼 수 있는가? | genre | 정확 조건 |
| 2020년 이후, 평점 4.0 이상인 콘텐츠만 추릴 수 있는가? | release_year, rating | 범위 |
| 조회수가 높은 순으로 인기 콘텐츠를 정렬할 수 있는가? | view_count | 정렬 / 집계 |

## 5. 제외할 데이터
- 수집하거나 저장하지 않을 개인정보: 사용자 이름, 이메일, 시청 기기 고유 식별자(IMEI/MAC), 결제 정보, 정확한 위치(GPS) 좌표
- 제외 이유: 콘텐츠 검색 인덱스는 콘텐츠 메타데이터만 다루면 되고, 개인 식별 정보를 담을 필요가 없음. 또한 CPPG(개인정보관리사) 관점에서도 불필요한 개인정보 수집·저장은 최소화 원칙에 위배됨
