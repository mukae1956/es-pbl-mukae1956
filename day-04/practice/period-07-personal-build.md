## (개인·필수) 문제 2 — 청사진대로 서로 다른 패널 4개 제작

질문 Q1~Q4를 답하는 패널을 최소 4개 만드세요. 공통 Dashboard와 비교해 field·집계·정렬·구간·제목 중 두 가지 이상을 개인 질문에 맞게 바꿉니다.

| 질문 | 패널 제목 | field | 계산·그룹 | 차트 | 실제 결과 | 완료 기준 통과 |
|---|---|---|---|---|---|---|
| Q1 | 전체 콘텐츠 수 | (Records) | Count of records | Metric | (실습 후 직접 기록, 예상 1000) |  |
| Q2 | 장르별 콘텐츠 수 | genre | Top values + Count | Bar | (실습 후 직접 기록, 예상 SF 157/드라마 156/멜로 143/코미디 142/다큐 135/스릴러 135/액션 132) |  |
| Q3 | 평점 구간별 콘텐츠 수 | rating | Create custom ranges(0.5 단위) + Count | Bar | (실습 후 직접 기록, 예상 min2.0/max5.0/avg3.54) |  |
| Q4 | 시청 가능 비율 | available | Top values + Count | Donut(Pie→Donut hole) | (실습 후 직접 기록, 예상 true 690/false 310) |  |

- 공통본에서 변경한 요소 2개 이상: field(category→genre, brand→없음), 차트 구성(가격 Bar→평점 Bar, 재고 Donut→시청가능 Donut), 개인 index(products→contents) 사용
- 만들지 못한 패널과 이유: 월별 등록 추이 Line은 contents에 날짜 field가 없어 이번에는 제외(6교시 데이터 보강 계획 참고)
- 사용한 대체 질문 또는 데이터 보강 계획: `../evidence/day-04/dashboard-plan.md`의 4절(added_at 필드 추가 규칙) 참고

## (개인·필수) 문제 3 — 제목과 배치만 보고 질문을 이해하게 만들기

각 제목을 `Bar`, `그래프`, `현황` 같은 차트 이름이 아니라 사용자가 알게 되는 내용으로 바꾸세요.

| 수정 전 제목 | 수정 후 제목 | 사용자가 알게 되는 것 |
|---|---|---|
| Bar | 장르별 콘텐츠 수 | 어느 장르가 많고 적은지 |
| Bar | 평점 구간별 콘텐츠 수 | 저평점/고평점 콘텐츠가 어디에 몰려 있는지 |
| Donut | 시청 가능 비율 | 지금 바로 볼 수 있는 콘텐츠가 얼마나 되는지 |
| Metric | 전체 콘텐츠 수 | 카탈로그 전체 규모 |

- 가장 중요한 패널: 전체 콘텐츠 수 Metric(다른 패널 판단의 기준값이 되므로)
- 가장 크게 배치한 이유: 장르별 콘텐츠 수 Bar — 장르명이 길어 겹치지 않게 넓은 폭 필요
- 잘림·겹침을 수정한 패널: (실습 후 직접 기록)
- 수정 후 전체 화면 캡처: (실습 후 직접 첨부)
